# ComfortCommute

I built an app to make our daily commute using public transport, more efficient. I plan to have user input, leading to better planning and also AI integration to help recommend routes for the user. This will be based on priorities that the user can choose, namely comfort versus time. This will further branch out into users being able to filter by seat availability etc. This app will be a massive upgrade to the current app called MyTransport. It will also be the app notifying users on whether their favourites are affected by any incidents or crowd mitigation plans.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://comfortcommute.lovable.app
